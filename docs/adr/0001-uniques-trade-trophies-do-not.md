# Uniques can be traded, trophies cannot

Players should be able to get rich, so materials, gear and most boss uniques trade freely between players. A small set of trophies stays with whoever earned them, so that some possessions still prove what a player has done. Changing this later would take away value that players already hold.

## Considered Options

- **Uniques bound to their owner, only materials trade.** Agreed at first, then dropped: the best drops would never enter the economy.
- **Everything trades.** Rejected: nothing would show personal achievement.
- **No trading.** Rejected: one player could do everything, with no reason to rely on others.

## Consequences

Because uniques keep their value only while they are scarce, drop rates and coin sinks matter far more than they would in a game without trading.
